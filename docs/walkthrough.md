# Руководство по проекту (Walkthrough): Calendar Booking API

Добро пожаловать в документацию Calendar Booking API. Этот документ поможет вам понять, как устроена система и как начать с ней работать.

---

## 1. Архитектурная концепция

Система построена на принципе **Stateless API** с интеграцией внешнего провайдера данных (Google Calendar).

### Ключевая логика "Freebusy на лету":
Мы не храним копию календаря пользователя в нашей базе данных. Вместо этого:
1. Пользователь запрашивает свободные слоты на дату.
2. Система берет рабочие часы из локальной БД.
3. Система делает запрос в Google Calendar через API (`freebusy`), чтобы узнать занятые интервалы.
4. `SlotEngine` вычитает занятое время из рабочего графика и возвращает доступные окна.

Это обеспечивает максимальную приватность и актуальность данных.

## 3. Основные эндпоинты

### 🔑 Авторизация (OAuth2)
- `GET /api/v1/auth/login` — инициирует вход через Google.
- `GET /api/v1/auth/callback` — обработка ответа от Google и выдача JWT.

### 📅 Настройка графика
- `POST /api/v1/organizer/working-hours` — установка рабочих часов (например, Пн-Пт 10:00-18:00).

### 🔍 Поиск слотов и бронирование
- `POST /api/v1/slots/available` — получение списка свободных окон на конкретную дату.
- `POST /api/v1/bookings` — создание бронирования. **Важно:** реализована защита от двойной записи (Race Condition) на уровне БД.

## 4. Фронтенд-архитектура

Для фронтенда мы используем «регламентный» стек: **React + Vite + Vanilla CSS** (для максимальной гибкости и WOW-эффекта).

### Ключевые принципы фронтенда:
1. **Mobile First:** Интерфейс проектируется под Telegram Mini App (вертикальная ориентация).
2. **Smooth UX:** Использование микро-анимаций при выборе слотов.
3. **JWT Storage:** Токен авторизации хранится в `localStorage` и автоматически подставляется в заголовки запросов (`Authorization: Bearer <token>`).

## 6. Деплой и CI/CD

### Фронтенд (GitHub Pages)
Проект настроен на автоматическое развертывание. 
- **URL:** [https://3dstepansky.github.io/calendar-booking/](https://3dstepansky.github.io/calendar-booking/)
- **Backend (VPS):** `http://45.134.217.246:8000`

> [!WARNING]
> **Mixed Content:** Поскольку фронтенд работает на HTTPS, а бэкенд на HTTP, браузеры могут блокировать запросы. Для полноценного тестирования рекомендуется запускать фронтенд локально или настроить SSL на сервере.

### Уведомления (Telegram)
Система отправляет уведомления о новых записях. Для активации нужно:
1. Создать бота в `@BotFather`.
2. Прописать `TELEGRAM_BOT_TOKEN` и `ADMIN_CHAT_ID` в `.env`.

## 8. Стек технологий
- **FastAPI:** Асинхронный фреймворк для API.
- **SQLAlchemy 2.0 + asyncpg:** Работа с базой данных PostgreSQL.
- **Pydantic v2:** Валидация данных и схемы.
- **Google API Client:** Интеграция с сервисами Google.
- **Alembic:** Управление миграциями.
