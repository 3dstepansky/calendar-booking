# План реализации (Implementation Plan): Calendar Booking API

## Цель проекта
Создать надежный бэкенд для записи к специалисту через Telegram Mini App с двусторонней синхронизацией через Google Calendar API.

## 4. Стандарты визуального качества (Visual Excellence)

После аудита Step 2 были внедрены следующие стандарты, обязательные для всех новых страниц:

1.  **Glassmorphism 2.0:** Использование `backdrop-blur` (минимум 12px) и `bg-white/[0.03]` для карточек. Границы должны иметь градиент `border-white/5` для эффекта тонкого стекла.
2.  **Акцентное свечение:** Кнопки и активные элементы должны иметь мягкую тень в цвет бренда (Sky-500) с прозрачностью 0.2-0.3.
3.  **Иконографика:** Использование только `lucide-react`. Все иконки действий должны иметь контейнер с легким фоном (bg-accent/10).
4.  **Анимации:** Обязательное использование `AnimatePresence` для смены вкладок. Переходы должны быть `easeOut` с длительностью 0.3-0.4с.
5.  **Typography:** Основной шрифт — **Outfit**. Использование `tracking-tight` для заголовков и `tracking-widest` для микро-лейблов в верхнем регистре.
6.  **Mobile Adaptive:** На мобильных устройствах интерактивные элементы (кнопки удаления) должны быть доступны без наведения (hover).
